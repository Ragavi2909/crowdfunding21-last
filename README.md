# 🌱 GreenFund – Crowdfunding Platform

## 📌 Project Description
GreenFund is a full-stack crowdfunding platform designed to support eco-friendly and sustainable initiatives.

Users can create fundraising campaigns, donate securely, and track progress in real time, while admins manage approvals and user verification.

---

## ⚙️ Tech Stack

### 🖥️ Backend
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT Authentication
- bcryptjs
- Multer

### 🎨 Frontend
- HTML
- CSS
- JavaScript

### 💳 Other Tools
- Razorpay (Payment Gateway)
- dotenv (Environment Config)

---

## 🚀 Features

### 👤 User Features
- Register & Login  
- Create Campaigns  
- Donate to Campaigns  
- Track Donations  
- Personal Dashboard  
- KYC Verification  

### 🛡️ Admin Features
- Campaign Approval System  
- User Management  
- KYC Verification Control  
- Analytics Dashboard  

### 📢 Platform Features
- Real-time fundraising progress  
- Secure payment integration  
- Image uploads for campaigns  
- Responsive design (mobile-friendly)  
- RESTful API architecture
